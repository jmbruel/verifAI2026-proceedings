## Status Values

- **Camera-Ready Received / Source Files Received / Licence-to-Publish Signed:** `No`, `Yes`, or ISO 8601 date (`YYYY-MM-DD`).
- **Page Count:** Positive integer or `—` when not yet determined.
- **Compliance Check:** `Pending`, `Pass`, or `Fail` (see `tracking/compliance-rules.md`).
- **Compilation Status:** `Pending`, `OK` (LaTeX compiles cleanly inside `papers/p<sub-id>/` via `make paper`), `Error`, or `N/A` (Word `.docx` submission).

## Failure Note Convention

When **Compliance Check** is set to `Fail` or **Compilation Status** is set to `Error`, add a blockquote on the line immediately below the affected table row citing `CR-1` through `CR-5` or the LaTeX build error. Once the author corrects the issue and resubmits, reset Compliance Check / Compilation Status to `Pending` while the revised submission is under review.
