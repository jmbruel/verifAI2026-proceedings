%
%   3. Compile from the workspace root:
%
%        make proceedings
%
%      or manually:
%
%        pdflatex proceedings.tex
%        pdflatex proceedings.tex   % second pass for TOC/refs/running heads
%
%   4. llncs.cls is at the workspace root; pdflatex finds it automatically
%      when run from that directory.
%
%   5. Set topical Part Titles once section groupings are decided (see
%      submission/toc.csv "Part Titles" column); replace the PLACEHOLDER
%      text in each \part{} command below.
